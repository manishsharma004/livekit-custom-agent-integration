Voice agent demo for your local cluster.

This browser demo creates a LiveKit room, dispatches the agent, joins with your microphone, and plays remote audio back in the page.

Microphone preferred Use a browser on the same machine as MicroK8s so ws://127.0.0.1:7880 can reach LiveKit. If microphone APIs are unavailable in the current browser context, the demo still joins in listen-only mode.
Demo-only flow The backend issues participant tokens and performs explicit agent dispatch for each room. Speech goes through LiveKit Inference and Kokoro, while the LLM step uses local Ollama Gemma.
